# Spring 1995 from power-on through real pad input (pc/tools/playthrough.py):
# a club, a girl's first appearance, the sports festival's ball rolling and
# the club's practice match.
#
# The new game of new_game.txt to the first school day (Tue 4 Apr 95), then:
# - the night schedule's 雑学 (general knowledge) icon, every week;
# - Sun 9 Apr: the holiday screen's club icon (icon 4, shown on Sundays
#   with no club) -> the club list -> tennis (basyo_pack club 8);
# - the third Sunday of every month (16 Apr, 21 May, 18 Jun) the club icon
#   again -> "club activity" (holiday_club, menu 0): a sports club member
#   who spends that Sunday elsewhere gets the answering-machine call
#   (TEL sub-step 8, schedule_day_main) and leaves the club; the
#   club_kept checks read the club nibble only (basyo_pack & 0xF000):
#   the low bits are location flags the rand-decided June events set on
#   some runs and not others (0x8100 on 11 Jun in one port run);
# - a girl's first appearance, scene 91 (SHOUGATU; schedule type 72 from
#   touzyou_check: 雑学 >= 36 brings girl 8, rand() % 3 per school day,
#   not in April 95);
# - Sat 3 Jun: the sports festival (scene 114, TAIIKU): "another event"
#   -> ball rolling (TAMA2.TMD, drawn by GsTMDfastTG3LFG: lit, fogged)
#   -> the partner plate -> the race, circle tapped to push;
# - Sun 18 Jun: the club icon -> club activity -> holiday_club_exit:
#   a sports club, the third Sunday of a month divisible by 3 ->
#   scene 115 (RENSYU, the practice match).
#
# Pointer screens park the hand in the clamp corner (-150,-100) first, as
# in new_game.txt (3 px per held frame).  Icon boxes (traced now_icon):
# columns x -147..-129 / -123..-105 / -99..-81, rows y -46..-40,
# -34..-22, -16..-4, 8..20, 26..32; icon 5 (雑学) is row 2 column 0.
#
# Between the screens it acts on, the script taps circle (`mash`) with the
# hand on icon 5: through dialogue, through the weekday events the kernel
# rand decides (walks home, phone calls, girls' first appearances -- the
# port and the reference see a different rand: srand(vblnk_counter) at the
# title), and on any holiday screen it picks 雑学 again.  Which days the
# events fall on therefore differs between the two machines; the scripted
# milestones do not.
