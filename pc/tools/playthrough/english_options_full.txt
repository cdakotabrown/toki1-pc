# pc/tools/checkpoints/play/option_config.txt: with a pad the hand snaps to
# the rows of menu 0 (now_icon) and the d-pad steps them; circle opens row

# entries (menu_csr), so a few down presses show every entry's highlighted
# frame.  The extras (row 6) need a system file with a clear: run it with
# --start-card <a cleared card> for those (without one the extras menu is
# empty and the script still passes: its rows are reported, not required).
#
#   python3 pc/tools/playthrough.py pc/tools/playthrough/english_options_full.txt \
#       --set TOKI_LANG=en --shots
