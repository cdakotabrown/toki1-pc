# A date and an in-game save, from power-on through real pad input
# (pc/tools/playthrough.py).
#
# The new game of new_game.txt up to the first holiday (Sun 9 Apr 95), then:
# the holiday screen's telephone -> the phone book -> Shiori -> "choose the
# day" calendar (Sun 16 Apr) -> "choose the place" (the neighbourhood
# park) -> she agrees (reserved_date); the night schedule picks the first
# study icon for the week; on Sun 16 Apr the holiday screen's heart icon
# goes to the date (DATE overlay, now_step 0x50): the park, Shiori's
# bust-up, one conversation choice, home.  The night schedule's save icon
# -> save -> album 1 -> overwrite (o) -> the card write.  Then a reboot on
# the same card loads album 1 and the player record, calendar and Shiori's
# record equal the saved ones.
#
# Pointer screens park the hand in the clamp corner (-150,-100) first, as
# in new_game.txt; it moves 3 px per held frame.  Dialogue is advanced
# with cross: xa_wait_m takes circle or cross (pad_trig & 0x60), and a cross
# that spills past the last line onto the schedule screen selects nothing.
# Lines with an XA voice wait for the voice (voice_level 2), so the number
# of presses a conversation takes is not fixed: each conversation ends
# with a wait on the screen that follows it.  The kernel rand differs from
# retail (srand(vblnk_counter) at the title; the PC's movie phase is 6
# VBlanks short), so Shiori's "machiawase" lines (D_8015BF2C) can differ.
