Tokimeki Memorial: Forever with You): licences

Corresponding source: every release of this program is published together
with a source archive named like the download plus "-source.tar.gz"
(for example tokimeki-pc-windows-source.tar.gz).  It holds the complete
source tree the program was built from and the DuckStation SPU files with
this project's patches applied, and is published in the same place as the
program.  If you received this program without that archive, ask whoever
gave it to you for it: the GPL requires them to provide it.

It contains no disc data (no art, music, video or Japanese script text):
the game's files are extracted on your computer from your own disc.  It
does contain an unofficial English translation of the game's script, a fan
translation of Konami's text.

The PC port's own code is GPL-3.0-or-later; two of its files, which
contain DuckStation-derived code, are GPL-3.0-only.  The decompilation
project it is built from is MIT outside the PC port (PROJECT-MIT.txt).
This program as a whole is GPL-3.0.
