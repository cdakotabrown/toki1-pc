# Proportional Latin pixel font for the PS1 English patch (12 px tall).
# Authored by hand for this project (2026-10-08); not derived from any game
# or third-party font.  Format: one "glyph <char> adv <N>" header, then 12
# rows of '.'/'#'.  Rows may be shorter than the box; the box is adv-1 px
# wide (the last column is the 1-px inter-glyph spacing).  Rows 1-9 are the
# cap height, 4-9 the x-height, 10-11 descenders, row 0 is empty.
# The character after "glyph" is the ASCII char; "space" names 0x20.
# tools/patch/fontgen.py compiles this into C tables and a JSON metrics file.
