# PC-only glyphs for the PC layer's UI text (settings menu, setup screen,
# notes, save browser, status page, extras), drawn beside
# tools/patch/font/latin12.txt -- the English patch's hand-authored 12-px
# Latin font, which owns every ASCII character and is not changed for the
# UI.  These are symbols latin12 has no reason to carry: an ellipsis for
# cut-off text, arrows for the key help, the pointer triangles of a choice,
# the heart that marks the selected row.  Authored by hand for this project
# (2026-11-02); not derived from any game or third-party font.
#
# Same format as latin12.txt: "glyph U+XXXX adv N", then 12 rows of '.'/'#'
# (row 0 empty, rows 1-9 the cap height, 4-9 the x-height, 10-11
# descenders); the box is adv-1 px wide, the last column the 1-px spacing.
# pc/tools/gen_ui_font.py compiles both files into the UI font; a code
# point below U+0080 here is refused (latin12 owns ASCII).
